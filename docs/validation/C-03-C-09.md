## Limites et réserves de livraison

- La couverture de cours automatiques actions/ETF/crypto reste ouverte : saisie manuelle uniquement pour les actifs. Seul le FX BCE est connecté. Les licences d’un fournisseur tiers ne sont pas présumées autoriser l’export ou une instance publique multi-utilisateur.
- Retenues fiscales, conversions et transferts de courtier ambigus ne sont pas automatiquement normalisés. Un lot contenant une telle ligne est bloqué ; le rapport indique l’anomalie. PRU économique, aucune promesse fiscale française.
- Récupération de compte absente ; pas de recette avec lecteur d’écran, de charge chiffrée, de matériel ARM64 physique ni d’installation sur le mini-PC cible.
- Le timer systemd quotidien est fourni comme exemple, pas activé dans ce workspace. Pas de déploiement public, de domaine réel ni de certificat public émis par cette session.
- L’environnement rootless utilise un stockage Docker vfs de capacité limitée : builds séquentiels avec nettoyage des caches de compilation de cette tâche, volumes de bases conservés. Aucune désactivation de TLS ni de contrôle d’accès pour obtenir une réussite.

Ces éléments empêchent de déclarer la publication MVP globale terminée. Les statuts doivent distinguer comportement implémenté, recette locale et déploiement cible.
