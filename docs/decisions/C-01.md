# Décisions et démarrage C-01

2026-11-05. Autorité : demande explicite du responsable produit de prendre les décisions, les écrire et commencer le développement, après C-00. ADR-0004 et ADR-0005 passent à accepted sur cette délégation ; ce n’est pas une approbation humaine détaillée de chaque technologie.

## Choix acceptés

- Monolithe modulaire : un backend et des frontières métier, sans microservices ni framework de plugins. Limite la charge opérationnelle ; les modules seront créés avec leurs usages, pas sous forme de dossiers vides.
- React 19.3.1, TypeScript 6.0.3, Vite 8.3.6 ; Node 22.22.1 pour la chaîne vérifiée. Versions exactes et dépendances transitives dans `web/package-lock.json`. React prépare les interactions complexes ; TypeScript vérifie les contrats ; Vite sépare la compilation de l’application du backend.
- Go 1.27.3, bibliothèque standard HTTP pour ce socle : binaire autonome, logique métier testable sans navigateur. Deux chaînes de compilation sont le coût assumé par rapport à une solution TypeScript intégrale.
- PostgreSQL retenu pour la future persistance transactionnelle. Version et pilote seront fixés lors du lot de persistance, après vérification ; aucun serveur, schéma ou accès DB créé ici.
- Docker Compose Linux et Apache 2.0 conservés. Aucun service externe payant requis.

Les versions publiées ont été consultées via npm et la [distribution officielle Go](https://go.dev/dl/). Les prérequis Node sont décrits par [Vite](https://vite.dev/guide/). Les licences et quotas de cours ne sont pas déduits de ces choix.

## Portée implémentée

ROADMAP C-01 / P0.12 ; NFR-13, préparation F-022. Backend minimal, liveness publique sans données privées, compilation frontend en bibliothèque technique, tests de fumée et workflow CI. Le frontend n’est pas une page produit : aucun dashboard, donnée de démonstration ni connexion simulée. Le point de santé prouve uniquement que le processus répond, pas que le MVP ou une base est disponible.

## Décisions différées

Les ADR-0006 à 0009 restent proposés. L’exactitude décimale, l’isolation serveur et la traçabilité sont déjà obligatoires ; leurs contrats détaillés ne sont pas implémentés dans C-01. Q-02/Q-03 nécessitent des scénarios économiques cohérents avant ledger. Q-01/Q-05 exigent des échantillons réels anonymisés ou une liste d’actifs ; Q-06 exige des preuves de couverture et de licence. Une délégation de choix ne remplace pas ces preuves.

Pas de stockage hors ligne privé dans C-01. REST, authentification, récupération et conservation seront contractualisés avant leurs lots. Aucun périmètre P1/P2 ajouté. Phase 0 non terminée ; C-00 reste le constat historique avant cette délégation.
